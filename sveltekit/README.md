# Virtual Module Core - TypeScript/SvelteKit Implementation

This directory contains the TypeScript/SvelteKit implementation of the `virtual-module-core` library.

## Overview

This is the TypeScript package that provides:
- Dependency Injection container
- Module registry and routing
- SvelteKit adapter for virtual modules
- Type definitions for module bundles

## Development

```bash
# Install dependencies
npm install

# Build
npm run build

# Watch mode
npm run dev

# Test
npm test

# Lint
npm run lint
```

## Publishing

This package is published as `virtual-module-core` from the repository root. The root `package.json` exports point to the compiled output in this directory.
